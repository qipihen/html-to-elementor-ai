## 一、项目概述

### 1.1 项目背景

HTML To Elementor 是一个 Chrome 浏览器扩展程序，帮助用户将网页元素转换为 WordPress Elementor 小部件。原版通过规则引擎实现基础转换功能。

### 1.2 增强目标

在原版基础上增加 AI 智能优化功能：
- 智能代码优化 - AI 自动优化 CSS，生成更精简的 Elementor 控件配置
- 布局还原增强 - AI 补全丢失的样式信息，更精确还原设计意图

## 三、功能设计

### 3.1 原有功能（保留）

| 功能 | 描述 |
|------|------|
| 元素捕获 | 点击页面元素，提取 HTML 和 CSS |
| 高亮显示 | 选中的元素有视觉标记 |
| 代码复制 | 一键复制转换后的代码 |
| 设备预览 | 模拟不同设备（手机/平板/桌面）尺寸 |
| 数据持久化 | 保存捕获的元素数据 |

### 3.2 新增 AI 功能

#### 3.2.1 AI 优化处理

**CSS 优化**：
- 识别并移除冗余/重复的样式属性
- 合并可合并的样式（如多个 border 属性）
- 简化复杂的颜色值（rgba → hex）
- 优化为最精简的 Elementor 控件配置

**布局增强**：
- 分析设计意图，补全缺失的间距（margin/padding）
- 识别字体层级，补全字体样式
- 分析布局结构，还原 Flexbox/Grid 意图
- 补全继承丢失的样式

#### 3.2.2 触发方式（混合模式）

- **手动触发**：用户点击"AI 优化"按钮才调用 AI
- **自动检测**：在设置中开启"每次自动优化"后自动调用

#### 3.2.3 结果展示

| 展示形式 | 描述 |
|----------|------|
| 标签切换 | 提供"原版"和"AI优化版"两个标签页 |
| 优化说明 | 简单文字描述优化内容（如"简化了 12 个冗余样式"） |
| 截图对比 | AI 处理前后分别截图展示 |
| Elementor 模拟 | 在面板中模拟 Elementor 组件渲染效果 |

#### 3.2.4 错误处理

- AI 处理失败时自动使用原有规则引擎的结果
- 显示提示告知用户 AI 处理失败
- 提供"重试"按钮

## 八、用户体验设计

### 8.1 首次使用流程

1. 用户安装扩展
2. 捕获元素时检测到未配置 AI
3. 提示用户去设置页面配置 API
4. 用户配置并保存
5. 正常使用时 AI 功能

### 8.2 正常使用时

1. 点击扩展图标启用捕获
2. 点击页面元素
3. 显示原版结果
4. （如果启用 AI）自动/手动触发 AI 优化
5. 显示 AI 优化版结果 + 优化说明
6. 用户选择版本并复制

### 8.3 错误提示

| 情况 | 提示方式 |
|------|----------|
| API 未配置 | Toast 提示 + 设置按钮 |
| API 测试失败 | 设置页面显示错误信息 |
| AI 处理失败 | 降级到原版 + 显示失败提示 |
| 网络错误 | Toast 提示"网络错误，请重试" |

## 十、总结

本设计在原有 HTML To Elementor 插件基础上，通过集成 OpenRouter AI 服务，实现智能代码优化和布局还原增强功能。保持了原有 UI 设计风格，新增 AI 配置面板和结果对比展示，让用户可以直观地看到 AI 优化效果并自主选择使用原版还是 AI 优化版。
